# 🥇 Gold Layer

## Overview

The Gold layer represents the business intelligence layer of the retail analytics pipeline. It transforms validated retail events from the Silver layer into aggregated, business-ready datasets that support decision-making, performance monitoring, and executive reporting.

By computing product-level metrics and customer behavior KPIs, the Gold layer delivers actionable insights into sales performance, conversion efficiency, shopping behavior, and product demand. These analytics-ready datasets are optimized for Power BI dashboards and downstream business intelligence applications.

## 📊 Component — Gold Data Aggregation

### Purpose

The Gold Data Aggregation component transforms validated retail events into high-value business metrics by aggregating customer interactions at the product and category levels. It summarizes transactional data, analyzes customer behavior, and computes key performance indicators that enable data-driven decision-making.

The resulting Gold dataset provides a consolidated view of sales activity, customer engagement, product performance, and purchasing trends, making it suitable for executive dashboards and business reporting.

### Key Responsibilities

* Reads validated events from the flash_sale_silver table.
* Aggregates retail events by product and category.
* Calculates total events, units sold, and total revenue.
* Tracks customer behavior through views, cart additions, and purchases.
* Computes product conversion rates.
* Calculates cart abandonment percentages.
* Measures product demand pressure.
* Computes average order value per purchase.
* Generates recency-weighted trending scores to identify high-demand products.
* Produces analytics-ready datasets optimized for reporting and visualization.

### Business KPIs Generated

## Aggregation Logic

The Gold transformation performs several analytical operations before producing the final business dataset.

* Groups retail events by Product ID and Category.
* Aggregates sales volume and revenue metrics.
* Separates customer interactions into views, carts, and purchases.
* Calculates conversion rates using purchase-to-view ratios.
* Computes cart abandonment based on cart and purchase events.
* Measures demand pressure using event-to-unit ratios.
* Calculates average order value for completed purchases.
* Applies recency-based weighting to identify trending products.
* Excludes incomplete records to ensure reporting accuracy.

## Source Code

```SQL
DROP TABLE IF EXISTS flash_sale_gold;

CREATE TABLE flash_sale_gold AS
SELECT
    ROW_NUMBER() OVER () AS id,

    product_id,
    category,

    -- total counts
    COUNT(*) AS total_events,
    COALESCE(SUM(quantity),0) AS total_units,
    COALESCE(SUM(revenue),0) AS total_revenue,

    -- behavior breakdown
    SUM(CASE WHEN event_type='view' THEN 1 ELSE 0 END) AS views,
    SUM(CASE WHEN event_type='cart' THEN 1 ELSE 0 END) AS carts,
    SUM(CASE WHEN event_type='purchase' THEN 1 ELSE 0 END) AS purchases,

    -- conversion rate % (purchase/view)
    COALESCE(
        ROUND(
            SUM(CASE WHEN event_type='purchase' THEN 1 ELSE 0 END)*100.0 /
            NULLIF(SUM(CASE WHEN event_type='view' THEN 1 ELSE 0 END),0)
        ,2)
    ,0) AS conversion_percentage,

    -- cart abandonment % (cart not purchased / cart)
    COALESCE(
        ROUND(
            (SUM(CASE WHEN event_type='cart' THEN 1 ELSE 0 END) -
             SUM(CASE WHEN event_type='purchase' THEN 1 ELSE 0 END)) *100.0 /
            NULLIF(SUM(CASE WHEN event_type='cart' THEN 1 ELSE 0 END),0)
        ,2)
    ,0) AS cart_abandon_percentage,

    -- demand pressure score
    COALESCE(
        ROUND(
            COUNT(*) * 1.0 / NULLIF(SUM(quantity),0)
        ,2)
    ,0) AS demand_pressure,

    -- avg order value per purchase
    COALESCE(
        ROUND(
            SUM(revenue) /
            NULLIF(SUM(CASE WHEN event_type='purchase' THEN 1 ELSE 0 END),0)
        ,2)
    ,0) AS avg_order_value,

    -- trending score (weighted by recency)
    SUM(
        CASE
            WHEN ts >= NOW() - INTERVAL 5 MINUTE THEN 5
            WHEN ts >= NOW() - INTERVAL 15 MINUTE THEN 3
            ELSE 1
        END
    ) AS trending_score

FROM flash_sale_silver
WHERE product_id IS NOT NULL
  AND category IS NOT NULL
  AND COALESCE(user_id,'') <> ''  -- remove any events without user ID
GROUP BY product_id, category;
```
